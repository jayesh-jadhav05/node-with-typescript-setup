Node.js + TypeScript + MongoDB + Prettier Starter Template
This repository provides a ready-to-use setup for building scalable and maintainable Node.js applications with TypeScript, MongoDB, and Prettier. It's designed to help students and developers quickly start their projects with clean code practices and a robust development environment.

Features
Node.js with TypeScript: Leverage the power of TypeScript for strong typing and modern JavaScript features.
MongoDB Integration: Pre-configured connection to MongoDB for database operations.
Prettier: Enforces consistent code formatting for a clean and readable codebase.
Express.js: Minimalist and flexible web framework for building APIs and web applications.
Nodemon: Automatically restarts the server during development upon detecting file changes.
